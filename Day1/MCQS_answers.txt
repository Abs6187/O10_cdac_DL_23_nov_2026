Section 1: Perceptron Foundations & Decision Boundaries
======================================================================

Q1. Who introduced the perceptron, and in which year?
A) Geoffrey Hinton, 1986
B) Frank Rosenblatt, 1958
C) Yann LeCun, 1989
D) Marvin Minsky, 1969
Answer: B) Frank Rosenblatt, 1958
Explanation: Frank Rosenblatt introduced the perceptron in 1958 as a foundational neural network model capable of learning.

Q2. What type of classification problem is a single-layer perceptron limited to solving?
A) Non-linearly separable problems
B) Multi-class clustering problems
C) Linearly separable problems
D) Unsupervised density estimation problems
Answer: C) Linearly separable problems
Explanation: A single-layer perceptron uses a linear decision function and can only classify data that can be separated by a straight line or hyperplane.

Q3. In a 2D input space, what represents a perceptron's decision boundary, and how does it generalize to higher dimensions?
A) A circle; a sphere
B) A curve; a spline
C) A line; a hyperplane
D) A step function; a sigmoid surface
Answer: C) A line; a hyperplane
Explanation: In 2D the linear decision boundary is a line, and in higher-dimensional spaces it generalizes to a hyperplane.

Q4. Which limitation of single-layer perceptrons motivated the development of multi-layer perceptrons (MLPs)?
A) Inability to compute weighted sums
B) Inability to handle non-linear decision boundaries
C) Lack of input features
D) Inability to use floating-point weights
Answer: B) Inability to handle non-linear decision boundaries
Explanation: Single-layer perceptrons fail on non-linearly separable data, which led to MLPs using multiple layers and non-linear activation functions.

Q5. Which layer of a multi-layer network extracts features and performs intermediate computations?
A) Input layer
B) Hidden layer(s)
C) Output layer
D) Bias layer
Answer: B) Hidden layer(s)
Explanation: Input layers receive features, hidden layer(s) perform intermediate computations and feature extraction, and output layers produce final predictions.

Section 2: Perceptrons vs. Neurons, Weights, and Bias
======================================================================

Q6. How do modern neural network neurons differ from simplified perceptrons?
A) Neurons cannot use activation functions
B) Neurons only perform binary linear classification
C) Neurons use various activation functions and can model complex, non-linear relationships
D) Perceptrons can approximate any continuous function on their own, while neurons cannot
Answer: C) Neurons use various activation functions and can model complex, non-linear relationships
Explanation: Modern neurons are more flexible than simplified binary perceptrons because they support diverse non-linear activation functions and complex mappings.

Q7. What do weights on connections between neurons determine?
A) Only the number of hidden layers
B) The strength, direction, and influence of the input signal on the neuron's output
C) The learning rate schedule
D) The type of loss function used during training
Answer: B) The strength, direction, and influence of the input signal on the neuron's output
Explanation: Connection weights are learned numerical parameters that control the strength, direction, and impact of each input signal.

Q8. Which equation correctly shows the linear combination z for input x, weight w, and bias b as given in the notes?
A) z = w + x * b
B) z = w * x + b
C) z = (w + b) / x
D) z = w * x - b
Answer: B) z = w * x + b
Explanation: For input x, weight w, and bias b, the weighted linear combination is z = w * x + b.

Q9. What role does the bias term b serve in a neuron?
A) It replaces the need for an activation function
B) It shifts the activation function left or right to add flexibility in fitting data
C) It forces weights to stay positive
D) It stops backpropagation during training
Answer: B) It shifts the activation function left or right to add flexibility in fitting data
Explanation: Adding a bias shifts the activation function along the input axis, giving the model extra flexibility to fit data.

Section 3: Activation Functions
======================================================================

Q10. Why is differentiability important for activation functions in deep learning models?
A) It guarantees zero training error in one epoch
B) It allows gradients to be computed for backpropagation and gradient-based optimization
C) It eliminates the need for weights and biases
D) It converts non-linear data into linear data
Answer: B) It allows gradients to be computed for backpropagation and gradient-based optimization
Explanation: Deep learning relies on gradient-based optimization (like gradient descent), which requires differentiable activation functions to compute gradients during backpropagation.

Q11. Which activation function maps inputs to a range between -1 and 1 and is zero-centered?
A) Sigmoid
B) ReLU
C) Tanh
D) Leaky ReLU
Answer: C) Tanh
Explanation: Tanh (hyperbolic tangent) outputs values in (-1, 1) and is zero-centered, which helps optimization compared to Sigmoid's (0, 1) range.

Q12. Which statement accurately describes ReLU in the provided notes?
A) Its equation is ReLU(x) = max(0.01x, x)
B) It maps values strictly between 0 and 1
C) It outputs x if positive and 0 otherwise, helping mitigate the vanishing gradient problem
D) It suffers from the same severe vanishing gradient issue as Sigmoid for large positive x
Answer: C) It outputs x if positive and 0 otherwise, helping mitigate the vanishing gradient problem
Explanation: ReLU(x) = max(0, x) passes positive inputs directly and zeroes negative inputs, helping avoid vanishing gradients for positive values.

Q13. What issue does Leaky ReLU help address by allowing a small non-zero gradient for negative inputs?
A) Exploding batch sizes
B) The "dying ReLU" problem where neurons become inactive and stop learning
C) Overfitting on small datasets
D) Non-differentiability at all positive values
Answer: B) The "dying ReLU" problem where neurons become inactive and stop learning
Explanation: Leaky ReLU (max(0.01x, x)) maintains a small positive slope for negative inputs so neurons do not get permanently stuck outputting zero.

Section 4: Backpropagation and Training
======================================================================

Q14. What are the two main steps of the backpropagation process listed in the text?
A) Data normalization and feature selection
B) Forward pass and backward pass
C) Initialization and pruning
D) Clustering and dimensionality reduction
Answer: B) Forward pass and backward pass
Explanation: Backpropagation first computes outputs and loss in the forward pass, then propagates errors backward to compute gradients and update weights in the backward pass.

Q15. How does backpropagation compute gradients of the loss function with respect to each weight?
A) Using the chain rule
B) Using random search
C) By setting biases to zero
D) By removing hidden layers
Answer: A) Using the chain rule
Explanation: Backpropagation applies the chain rule of calculus to compute the gradient of the loss with respect to each weight across layers.
