C-DAC ACTS, PUNE — COURSE SYLLABUS (PGCP-AI AUGUST 2026)
Module : Next-Gen AI: Deep Neural Networks
Source : 06_Next-Gen AI Deep Neural Networks.pdf
================================================================================

Duration: 120 Hours: 40 Theory (T) + 50 Lab (L) + 30 Self-Learning (SL)
Objective: To introduce students with deep neural network concepts.
Prerequisites: Knowledge of fundamentals of programming and basic mathematics &
  statistical knowledge.
Evaluation Method: Theory exam– 40%, Lab exam – 40%, Internal exam – 20%

List of Course material
-----------------------

Text Book:
  Deep Learning using Python, by S Lovelyn Rose, L Ashok Kumar, D Karthika Renuka,
  Wiley India, 1st Ed

Reference Book:
  1. Deep Learning, Ian Goodfellow, Yoshua Bengio, Aaron Courville
  2. Neural Networks and Learning Machines, Simon Haykin
  3. Hands-On Machine Learning with Scikit-Learn and TensorFlow
  4. TensorFlow Deep Learning Cookbook
  5. Reinforcement Learning with TensorFlow: A Beginner's Guide to Designing Self-
     learning Systems with TensorFlow and OpenAI Gym SayonDutta

    Introduction to Deep Neural Network

    • Activation Functions: Sigmoid, Hyperbolic Tangent, ReLu, Overview of Back

  Lab Assignment:
    • Implement the different activation functions on the Dataset in the Jupyter notebook.

--------------------------------------------------------------------------------

  Theory:
    • Introduction Deep Learning and Neural Networks
    • Practical Application of Neural Networks
    • "Hello World" of Neural Network (Logistic Regression)
    • Cost Function
    • Activation
    • Gradient Descent for Logistic Regression
    • Back propagation

  Lab Assignment:
    • Implement the main steps of a Shallow Neural Network
        - Understand the dataset
        - Implement your first Forward and Backward propagation
        - Implement activation function, gradient descent
        - Build Neural Network Model
        - Test and optimize the model
        - Make Predictions
          (to be done in Jupyter notebook. Need Jupyter-notebook and libraries
          installed)
